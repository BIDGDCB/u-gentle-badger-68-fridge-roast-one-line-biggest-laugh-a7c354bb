Entry for the make.fun competition
`u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb`.

`main.ts` writes a single one-line roast of a smart fridge to `/output/entry.txt`. The line is validated
before it is written: 1 to 200 characters, a single line, not only white
space.

The entry line:

> My smart fridge has a touchscreen, Wi-Fi, and a camera, yet somehow it still cannot tell the milk expired three weeks ago.
